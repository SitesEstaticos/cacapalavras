# Caça Palavras - Quick Start

## 🚀 Começar em 3 passos

### 1. Instalar dependências
```bash
npm install
```

### 2. Iniciar dev server
```bash
npm run dev
```

Acesse: `http://localhost:5173`

### 3. Começar a codar!
```bash
# Ver erros de tipo
npm run type-check

# Build para produção
npm run build
```

## 📁 Onde está cada coisa?

- **Lógica do jogo**: `src/services/GameEngine.ts`
- **Componentes**: `src/components/`
- **Hooks**: `src/hooks/index.ts`
- **Estilos**: `src/styles/globals.css`
- **Tipos**: `src/types/index.ts`
- **Documentação**: `docs/`

## 🎮 Jogar Agora

1. Clique em "Novo Jogo"
2. Escolha dificuldade
3. Selecione palavras com clique/arrasto
4. Use dicas se precisar
5. Veja seu score!

## 💡 Dicas para Desenvolver

- Usar path aliases: `@services`, `@components`, etc
- TypeScript strict mode ativado
- Sem `any` - sempre tipado
- Services são reutilizáveis
- Componentes são puras functions
